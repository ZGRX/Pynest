
# PyNest

PyNest is a FastAPI practice project for a product and order management backend.

Project target and learning roadmap: [PROJECT_GOAL.md](PROJECT_GOAL.md).

## Goal

Build a small but complete backend system with:

- user authentication
- product management
- orders
- payments
- admin dashboard APIs
- PostgreSQL
- Alembic migrations
- tests
- Docker deployment

## First milestone

- health check
- user registration
- user login with JWT
